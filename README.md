# Real-Time Payment Fraud Detection Engine

Streaming payment fraud detection engine using Kafka, Spring Boot, and Neo4j graph analytics with an ML risk score.

## Tech Stack
- Java, Spring Boot
- Apache Kafka
- Neo4j
- Python, scikit-learn
- React.js, WebSockets
- Docker

## Structure
- `ingest/` Kafka producers and payment event schemas.
- `engine/` Spring Boot scoring service with Neo4j graph rules.
- `dashboard/` React.js dashboard with live WebSocket alerts.
